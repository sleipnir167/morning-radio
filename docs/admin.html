GitHub に接続

この画面は保存も実行も GitHub API を直接呼びます。 トークンはこのブラウザの中だけに保存され、GitHub 以外へは送信されません。

Fine-grained トークンを作る → Repository access で morning-radio だけを選び、Permissions は Contents: Read and write / Actions: Read and write / Workflows: Read and write の3つ。

毎朝の実行時刻

日本時間で指定します。生成に10〜15分かかるので、散歩に出る1時間前が目安です。

GitHub の定時実行は混雑時に5〜20分ほど遅れて始まることがあります。 出発時刻ぎりぎりに設定しないでください。

曜日ごとのジャンル

その日のニュース検索の切り口にもなります。

ジャンル名を変えると news_queries の見出しと一致しなくなり、 ジャンル名そのものが検索語として使われます。細かく効かせたい場合は 「config.yaml」タブで news_queries にも同じ名前で検索語を足してください。

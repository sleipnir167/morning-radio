# 足元に眠る「水の道」と「人の足跡」を探る朝の散歩

薄曇りの空の下、朝の風を頬に受けながら歩いていると、ふと足元の道が緩やかに傾いていることに気づく瞬間はありませんか。

まっすぐな大通りから一本脇に入ると、なぜか道がゆったりとカーブしていて、わずかに低い場所へ吸い込まれていくような感覚です。

これ、実はあなたが今、かつて水が流れていた「川の跡」を歩いているからかもしれないんです。

こういう川の上に蓋をして作った道路のことを「暗渠（あんきょ）」って呼ぶんですけれど、街の歴史をひもとく一番の鍵なんですね。

例えば、おしゃれな店が立ち並ぶ東京の原宿や渋谷の裏通りにも、かつては渋谷川の源流となる小川が流れていました。

川そのものは昭和の都市開発で地下に埋められてしまいましたが、地面の形までは消せなかったんですね。

ちょっと想像してみてほしいんですけど、水って当然ですが、一番低い場所を選んで流れますよね。

何百年もの時間をかけて水が削り取った谷の浅いへこみが、今も私たちの足元に「数メートルの高低差」としてしっかり残っているんです。

今日みたいな薄曇りでしっとりとした朝は、特にその気配を感じやすい絶好の散歩日和です。

最初に都が置かれた「飛鳥」は、東と南と西の三方を山に囲まれた、静かな場所でした。
山に囲まれていると、外部の敵から守りやすいという大きな利点があったんです。

ここで、ちょっと想像してみてほしいんです。

水は当然、高い場所から低い場所へと流れますよね。
彼らはこの自然のルールを利用して、街の中に太くてまっすぐな水路や溝を、縦横無尽に張り巡らせました。
この水路は、普段は生活用水を届ける役割を果たしていました。
そして激しい大雨が降ったときには、街に溜まりそうになる雨水を、傾斜に従って一気に北西へと流し出す巨大な排水システムに変身したんです。

和歌山県の標高およそ800メートル。深い山々に囲まれた空中の宗教都市、高野山（こうやさん）をご存じでしょうか。

ちょっと想像してみてほしいんですけど、電車も車もない時代に、深い山奥の山頂を目指して、全国から旅人が歩いて集まってきたんです。

例えば、京都や大阪から皇族や貴族が参拝するときは、道標（みちしるべ）となる石の柱が立ち並ぶ「町石道（ちょういしみち）」を使いました。

一方で、商人たちが米や塩、木綿や油といった日用品を山の上に運び上げるときは、傾斜が少しゆるやかな別の峠道を選んでいたんです。

言ってみれば、旅客用の新幹線と、貨物用のトラック路線が、それぞれの役割を持ってひとつのターミナルに集まってくるようなシステムですね。

# 雲が隠す境界線と、足元から広がる地球の凸凹

みなさん、おはようございます。九月二日、水曜日の朝、いかがお過ごしですか。今朝の東京は心地よい薄曇りです。今朝は少し涼しいですが、お昼は暑くなります。調節しやすい上着があると安心ですね。折りたたみ傘もあるとさらに安心です。さて、今朝のテーマは「境界線」です。国境のような地図の線だけではありません。空気や地面にある見えない境界線が、実は歴史や地球の鼓動と結びついているんです。私たちが今歩いている足元にも、不思議な境界線が隠されているかもしれません。それでは、いってみましょう。【SE: 転換】

今朝の東京の空を見上げてみると、綺麗な薄曇りが広がっていますね。歩いていると、ちょうどいい涼しさを感じられる最高の散歩日和です。足元の気温はだいたい二十三度くらいで、湿気もそこまで高くなく、少しずつ秋の気配が近づいているのを肌で実感できる心地よさがあります。

これ、すごく面白いなと思うのが、この秋雨前線っていうのはただの雨雲の帯ではないんです。北からじわじわと降りてくる冷たい空気の塊と、南の海上から勢いよく北上してくる温かい空気が、真正面からぶつかり合ってせめぎ合う、いわば目に見えない空気の境界線なんですね。この二つの巨大な空気がどちらも一歩も譲らずに押し合いへし合いしているそのまさに足元に、日本列島を背骨のように南北へ貫く、あの急峻で険しい山々がドーンと立ちはだかっています。

この日本列島の複雑で高い地形が、まるで巨大な盾のようになって、空気がぶつかり合うその境界線を特定の場所にガッチリと固定してしまっているんです。冷たい風も温かい風も、日本の高い山にぶつかって行き場を失い、同じ場所で何度も雲を湧き上がらせることになります。だからこそ台風もその場で身動きが取れなくなり、日本各地に長雨をもたらす原因になってしまうんですね。私たちが普段何気なく見上げているあの山並みが、実は空の上で行われている巨大な空気の綱引きの勝敗をこんなふうに裏から支配していたなんて、ちょっと想像してみるだけでもうワクワクしませんか。

大空のせめぎ合いを支える日本の山々です。実はその山の尾根が、暮らしや言葉を分けるもう一つの境界線になっているんです。【SE: 間】

空から地上にふと目を向けてみると、今度は地面のほうにも、目に見えない強烈な線が引かれているんですね。

それが「分水嶺（ぶんすいれい）」です。
山の上で降った雨が、わずか一滴の差で、太平洋側に流れるのか、それとも日本海側に流れるのかを分けてしまう、あの稜線のことです。

これ、面白いのが、昔の人はこの水を分ける山肌をそのまま「国境（くにざかい）」にしていたんです。
今でいう都道府県の境目ですね。

山を登って向こう側に一歩足を踏み入れた途端、急に言葉のイントネーションが変わったり、お雑煮のお餅の形が丸から四角に変わったりする経験、ありませんか。
あれは単なる偶然なんかじゃなくて、ちゃんと地球の地形が仕掛けた理由があるんです。

# アスファルトの一歩下を掘り起こす、大地と記憶の地層散歩

- 放送日: 2026-09-09（水）
- ジャンル: 歴史・地理の雑学
- テーマ: 私たちが歩く現代の街の下に眠る、地理と歴史の隠された仕組みを読み解く
- 総文字数: 9267字

みなさん、おはようございます！9月9日水曜日の朝、いかがお過ごしですか？今朝の東京は雨。湿度が高くて蒸し暑いので、散歩の際は水分補給をお忘れなく。前回は、彦根城が江戸時代の姿を残す理由をお話ししましたね。今朝は、私たちが歩く足元の下に眠る、大地と歴史の記憶を掘り起こしていきます。まずは今朝のニュースから。なぜ大雨で道路が冠水するのか、都市の足元にあるアンダーパスの秘密に迫ります。普段通る道が、少し違って見えてくるかもしれません。それでは、いってみましょう！【SE: 転換】

しとしとと降る雨の中を歩いていると、ふと気になる場所がありませんか？
そう、線路や大きな道路の下をくぐり抜ける、すり鉢状の地下道です。
専門用語で「アンダーパス」と呼ばれる道路ですね。
大雨のニュースになると、よく「アンダーパスの集中規制」という言葉を耳にします。
……なんで水が溜まりやすいと分かっている場所が、街のあちこちにあるんだと思います？
ですよね、私も最初「もっと別の形にできなかったのかな」って思ったんです。

【SE: 間】

これ、実は日本の高度経済成長期にどうしても必要な解決策だったからなんです。
昭和三十年代から四十年代にかけて、街には一気に車があふれ出しました。
その結果、あちこちで「開かずの踏切」が生まれて、大渋滞や事故が深刻な問題になったんですね。
踏切をなくす一番の理想は、線路全体を高く持ち上げる「高架化（こうかか）」です。
ですが、高架化には莫大な費用と、何年もかかる長い工事期間が必要でした。

そこで選ばれたのが、道路側を掘り下げるアンダーパスだったんです。
鉄道を高架にするのと比べて、費用はおよそ数分の一で済み、工事も短期間で完了しました。
都市の急成長に追いつくために、安く素早く作れるアンダーパスは、当時の救世主だったんですね。

【SE: 間】

ちょっと想像してみてほしいんですけど、当時の設計基準ってどれくらいだったと思いますか？
実は、時間雨量で50ミリ程度の雨を想定して作られていました。
50ミリというと、傘をさしていてもずぶ濡れになるような激しい大雨です。
昭和の時代には「これだけの排水能力があれば十分だ」と考えられていたんですね。

ところが近年、私たちの頭上を襲う雨の降り方は大きく変わりました。
1時間に80ミリや100ミリを超えるような、滝のようなゲリラ豪雨が頻発しています。
すり鉢の底に設置された排水ポンプの能力をあっという間に超えてしまい、水が溜まってしまうわけです。

【SE: 転換】

これ、面白いのが、最近の冠水対策の進め方なんですよ。
街全体の地下排水管をすべて太くし直すのは、膨大な予算と時間がかかって不可能です。
そこで今は、テクノロジーを使った新しい対策が急速に進んでいます。

道路の底に設置したセンサーが冠水を検知すると、自動で進入禁止のゲートが降りる仕組みが増えています。
さらに最近では、気象レーダーと連動して、雨が強くなる前に危険を予測するAI（えーあい）、つまり人工知能を使ったシステムまで登場しているんです。
危険を力任せになくすのではなく、賢く回避する工夫へと進化しているんですね。

都市の地面をわざわざ深く掘り下げて作られたアンダーパス。
そこには、日本の発展を支えた歴史と、現代の最新技術が重なり合っていました。
都市の地面をわざわざ深く掘り下げて作られたアンダーパスから、今度は大地を深く掘り進めることで見えてくる「過去の歴史」の世界へと目を向けてみましょう。

アンダーパスの深い穴から、今度は北欧の土の中で見つかった大財宝のお話へ向かいましょう。【SE: 間】

北欧のフィンランドで、驚くようなニュースがありました。
趣味で金属探知機を楽しんでいた一般の愛好家が、なんと重さおよそ4.5キログラムもあるバイキング時代の銀貨を発見したんです。
枚数にすると千枚を超える大財宝でした。

ちょっと想像してみてほしいんですけど。
休日に近所の畑で宝探しをしていたら、一千年前の宝箱を掘り当ててしまったようなものなんです。

【SE: 間】

これ、面白いのが、なぜ専門家ではなく一般の愛好家がこれほどの大発見をできたのか、という点なんです。……なんでだと思います？
実は北欧では、「市民参加型考古学」という仕組みが定着しているんですね。

北欧の国々では、一般の人が金属探知機を使うことが認められています。
そして宝物を見つけたら、スマートフォンなどの位置情報と一緒に専門機関へ報告するルールが徹底されています。

もし歴史価値があるものだと分かれば、国が適切な価格で買い取って、発見者と土地の所有者に報奨金を支払います。
コソコソ隠すよりも、正しく報告したほうが感謝されて、正当なお金ももらえる仕組みなんですね。

プロの考古学者だけで広大な土地を調べるのには限界があります。
でも、ルールを守る何千人もの市民が「現地調査員」として協力すれば、発見の機会は一気に広がります。
市民と専門家が信頼し合って手を組んでいるわけです。

【SE: 間】

そして、今回見つかった銀貨ですが、中身を調べてみるとさらに面白い事実が分かってきました。
見つかった銀貨の多くは、およそ一千年前の10世紀に、イスラム世界で作られた「ディルハム貨」と呼ばれるコインだったんです。

バイキングと聞くと、海で暴れ回る荒くれ者を思い浮かべますよね。ですよね、私も最初そう思ったんです。
でも彼らは、世界を股にかける巨大な商人集団でもありました。

北欧からロシアの川をくだり、遠く中東まで船を進めて、毛皮などと引き換えにこの銀貨を手に入れていました。
北欧の静かな地面の下から出てきたコインが、世界を巡る交易の歴史を物語っているんですね。

【SE: 転換】

市民の好奇心と正しい仕組みが合わさることで、足元に眠る歴史のパズルが埋まっていきます。

土の中に隠された財宝が過去の交易を語るように、古代人が使っていた日常の道具もまた、高度な技術の記憶を現代に伝えています。

北欧の銀貨が語る交易から、今度は古代日本の職人が残した幻の道具の謎に迫ります。【SE: 間】

奈良時代の正倉院（しょうそういん）に、およそ1300年前の「漆塗り（うるしぬり）の革袋（かわぶくろ）」が伝わっています。

これを現代の熟練鞄職人（かばんしょくにん）たちが、1年がかりで完全復元しようというプロジェクトがありました。現代の高度な技術を使えば、すぐに完成しそうですよね？

ですが……なんでだと思います？ 実はこれが、現代のプロたちが頭を抱えるほどの難工事だったんです。

【SE: 間】

これ、何が難しいかというと、革と漆（うるし）という素材の組み合わせなんです。

みなさんも、普段お使いの革のバッグや靴を思い出してみてください。革って、柔らかくて、折り曲げたり伸びたりしますよね。

一方で、漆（うるし）は乾燥して固まると、ガラスのように硬くなる性質を持っています。ですから本来、柔らかい革に漆を塗ってしまうと、革を曲げた瞬間にパリパリとひび割れて、ボロボロに剥がれ落ちてしまうんです。

それなのに、1300年前の古代日本には、革のしなやかさを保ったまま、漆をしっかりと定着させる技術が存在していました。

【SE: 間】

ですが、その作り方を書いたマニュアルやレシピは、一切残っていません。まさに「失われた古代技術」だったんですね。

そこで現代の職人たちは、科学分析のデータをもとに、ゼロからの手探りで復元に挑みました。

革をなめす工程から見直し、漆に混ぜる天然の油の割合や、乾燥させる部屋の湿度まで、何十通りもの組み合わせを試しました。

ちょっと想像してみてほしいんですけど、顕微鏡も温度計もない時代に、昔の人は自分の感覚だけでこの配合を編み出していたんです。

ですよね、私も最初に聞いたときは本当に驚きました。これ、すごく面白くないですか？

【SE: 間】

何百回という失敗の末に、ついに漆がひび割れない絶妙な塗り方の順番と、塗料の組み合わせが突き止められました。

1年という歳月をかけて完成した革袋は、吸い込まれるような美しい黒い光沢を放ち、手で触れると吸いつくようにしなやかでした。

現代の職人技が、1300年前の職人の知恵と交差し、伝統工芸の未来を新しく拓いた瞬間だったんですね。

モノの技術だけでなく、人間の身体に残された「生と死の痕跡」を読み解くことで、さらに生々しい古代の暮らしが見えてきます。

正倉院の革袋に宿る古代の技術から、今度は出土した骨が語る生き様と暮らしを紐解きます。【SE: 間】

遺跡の現場から出土する一本の骨。一見すると、ただの白い塊にしか見えませんよね。
でも実は、骨こそが古代人の生き様をまるごと保存している「最小のタイムカプセル」なんです。
歴史の教科書には、王様や大きな出来事ばかりが記録されています。
文字を残さなかった普通の人々が、どんな日常を送っていたのか。それを教えてくれるのが、最新の考古学なんです。

最近「骨の考古学」という企画展でも話題になっていますが、人骨や動物の骨から歴史を読み解く形質（けいしつ）人類学という分野が、いま大きく進歩しています。

【SE: 間】

これ、面白いのが、その人が生前なにを食べていたかまで分かっちゃうことなんですよ。
それを可能にしたのが、骨の中に残された成分の分析です。
具体的には、炭素や窒素の「同位体（どういたい）比」という化学的なバランスを調べます。
人間は食べたもので作られますから、海のお魚や貝をメインに食べていたのか、それともお米や雑穀、陸の獣（けもの）肉を食べていたのかが、骨にハッキリ刻まれるんですね。
たとえば同じ時代に同じ地域で暮らしていても、男性と女性で食べ物が違っていたり、立場によって食卓が違っていたりしたことまで見えてきました。
文字には残されなかった毎日の献立が、数千年の時を超えて明かされるのって、ワクワクしませんか？

【SE: 間】

ちょっと想像してみてほしいんですけど、毎日ハードな労働をしていた人の体って、骨にどんな変化が出ると思います？
実は、骨の変形や傷を観察すると、当時の暮らしの苦労や「職業」まで推測できるんです。
例えば、縄文人の足の骨を調べると、太ももやスネの骨が現代人とは比べものにならないくらい、太くてがっしりしています。
舗装されていない山道や砂浜を、毎日何キロも歩き回っていた証拠なんですね。
さらに、特定の関節だけが異常にすり減っている骨が見つかることもあります。
これは、毎日同じ姿勢で重い道具を使っていた職人さんだったり、荷物を運び続けていた人だったりした、いわば「古代の職業病」の跡なんです。

それだけではありません。骨折して大きくズレた骨が、綺麗にくっついて治った跡が見つかることもあります。
……これ、どういうことか分かりますか？
骨折して動けない間、誰かが食べ物を運び、看病していた証拠なんですね。
骨の傷跡は、過酷な労働の記録であると同時に、当時の人々の助け合いや優しさの記録でもあるんです。

【SE: 転換】

名もなき人々が何を味わい、どんな汗を流し、どう支え合って生きていたのか。
歴史の表舞台には登場しない一人ひとりのリアルな人生が、一本の骨を通して鮮やかによみがえってきます。
足元の土の中に眠る骨は、時を超えて私たちに生き様を語りかけてくれる、愛おしいタイムカプセルなんですね。

人間の身体が残した歴史の跡から、今度は人々が集い、熱狂した「街の繁華街の地理史」へと視点を移してみましょう。

骨に刻まれた人間の生々しい暮らしから、30年越しの世界遺産候補、彦根城の物語へと渡ります。【SE: 間】

滋賀県の彦根城（ひこねじょう）。前回は、江戸時代の大名統治と城郭構造をそのまま残す貴重な遺構である理由をお話ししましたね。

実は最近、歴史ファンにとって本当に嬉しいニュースがありました。文化庁が、彦根城を2028年の世界文化遺産登録に向けて、正式に国内推薦することを決定したんです。

でも、ここでひとつ疑問が浮かびませんか。彦根城といえば国宝ですし、保存状態も抜群ですよね。……なのに、なぜ推薦が決まるまで30年以上もの時間がかかったのでしょうか？

【SE: 間】

これ、理由を聞くと「なるほど」と納得してしまいます。最大の壁は、1993年に一足早く世界遺産になった「姫路城」の存在でした。

ユネスコの審査には、「すでに登録されている遺産と内容が重なってはいけない」という非常に高いハードルがあるんです。

姫路城が日本の城の代表格として世界遺産に登録されたことで、彦根城は「同じような素晴らしいお城」というアピールだけでは、門前払いになってしまう状況が続いていました。

これ、面白いのが、ここからの大逆転のストーリーなんです。

【SE: 間】

地元や研究者のみなさんは、お城の「建物としての美しさ」だけで勝負するのを諦めました。その代わり、価値の捉え方を根底からガラリと変えたんです。

注目したのは、江戸時代という250年以上も平和が続いた、世界史でも珍しい時代の「社会の仕組み」でした。

彦根城は、お殿様の独裁ではなく、話し合いで政治を行う合議制（ごうぎせい）の舞台でした。さらに、城下町や琵琶湖を含めた地域全体が、平和な統治を行うために計算し尽くして作られていたんです。

単なる「かっこいいお城」ではなく、「泰平（たいへい）の世を支えた政治と暮らしの仕組み全体が残る場所」として価値を再定義したんですね。

【SE: 間】

ちょっと想像してみてほしいんですけど、お殿様がいたお城だけでなく、周りの武家屋敷や町人の街並み、水運の港まで、当時の構造がまるごと現代に残っているんですよ。

姫路城が軍事的な建築美の最高峰なら、彦根城は平和な社会システムを今に伝える唯一無二の遺産である。そうやって30年間の試行錯誤を経て、姫路城とは違う独自の意味を証明してみせたんです。

あきらめずに価値を掘り起こし続けた人たちの情熱には、本当に頭が下がりますよね。

歴史的な価値が時代を経て再評価されるように、私たちが普段歩いている都市の繁華街もまた、人の集積と文化の変遷によって形作られてきました。

価値が見直された彦根城に続いて、お墓の跡地から大エンタメ街へと化けた大阪・千日前を歩きます。【SE: 間】

みなさん、大阪の千日前（せんにちまえ）という街に行ったことはありますか？

なんばのすぐ近くにあって、劇場や賑やかな商店街が広がる、大阪を代表する繁華街ですよね。
でも実は、江戸時代の千日前は、お墓や刑場が広がる、人々がめったに近づかない場所だったんです。
……ちょっと意外じゃありませんか？

これ、面白いのが、そんな暗い歴史を持っていた場所が、わずか数十年で日本屈指のド派手な娯楽街へガラリと姿を変えたことなんです。
なぜ、お墓の跡地が庶民に愛されるカルチャーの発信地になれたんでしょう？

【SE: 間】

鍵になったのは、明治初期に行われた都市の大きな改革でした。
千日前は、江戸時代に法善寺（ほうぜんじ）などのお寺で、お経を千日間唱える「千日念仏（せんにちねんぶつ）」が行われていたことが名前の由来なんです。
そのお寺の周りには、広大な墓地や刑場が配置されていました。

ところが明治三年の１８７０年、衛生面や都市開発の理由から、これらのお墓が一斉に郊外へ移転させられたんです。

その結果、なにが起きたと思います？
なんと、大阪の街のすぐ隣に、広大なポッカリとした空き地が突如として生まれたんですよ。

都市の境界線、つまり「街のはずれ」に生まれたその場所は、地価が安く、一般的な家や店は建てにくかったんですね。
そこに目をつけたのが、あやしい見世物や芝居を見せる興行師（こうぎょうし）たちでした。

【SE: 転換】

この千日前を日本有数の興行街へと作り変えた中心人物が、奥田辨次郎（おくだべんじろう）という興行師です。
大阪歴史博物館の展示でも、彼の軌跡が詳しく紹介されているんですよ。

辨次郎は、ただ小屋を並べるだけではなく、街全体をテーマパークのように演出しました。
見世物小屋や芝居小屋を次々と集め、夜でも明るい照明を焚いて、道ゆく人々をワクワクさせたんです。

ちょっと想像してみてほしいんですけど、かつてのお墓の跡地に、珍しい動物や大道芸、カラフルな看板が所狭しと並んでいる光景です。
まさに庶民の熱気であふれかえっていたんですね。

【SE: 間】

千日前の勢いはそれだけでは止まりませんでした。
時代が明治から大正へ移ると、見世物小屋は新しいエンターテインメントへと進化していきます。
日本初の常設映画館のひとつである「電気館（でんきかん）」をはじめ、いくつもの映画館が建設されました。
庶民の欲望や新しいカルチャーをまるごと吸収しながら、街はますます巨大化していったんです。

お墓や刑場という「都市のはずれ」だったからこそ、広大な空き地が生まれ、常識にとらわれない文化が花開いた。
ネガティブな記憶を持つ土地が、人のエネルギーで一番賑やかな場所に生まれ変わるなんて、本当に面白いですよね。

人が集まる賑やかな街から、最後は自然災害という予期せぬ出来事が歴史の扉を開く現場へ目を向けます。

賑やかな繁華街から、今度は被災した古い家屋の解体現場で出会う未知の歴史史料のお話です。【SE: 間】

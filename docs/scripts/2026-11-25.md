# 冷たい風と土地の記憶：地図の余白に眠る歴史を歩く朝

みなさん、おはようございます。11月25日、水曜日の朝です。今朝の東京はどんよりとした曇り空。吐く息も白く、風が冷たく感じられますね。厚手の上着とマフラーが手放せない朝になりそうです。さて今朝の散歩ラジオですが、まずは今朝のニュースから。遠く離れた自治体にクマの苦情が殺到する背景について考えます。そして本編では、巨大な噴火から戦国の要塞まで、土地の歴史を歩きます。足元に眠る意外なドラマを、一緒に紐解いていきましょう。それでは、いってみましょう。【SE: 転換】

実は今年、東北地方をはじめとする各地の自治体に、「クマを殺さないで」「かわいそうだ」という苦情電話が何千件も殺到したんです。

これ、面白いのが、電話をかけている人の大部分が、クマの出没地域とはまったく関係のない遠く離れた都市部に住んでいる人たちだということなんですね。

大きな原因のひとつは、SNSによる情報の拡散です。

SNSでは、捕獲されたクマの画像や動画だけが短く切り取られて流れてきます。それを見た瞬間、直感的に「かわいそう」という感情が引き起こされるんですね。

自分自身の善意や過剰な正義感から電話をかけているため、相手の業務を妨害しているという自覚が持ちにくいのも、この現象の難しさなんです。

でも、ちょっと想像してみてほしいんですね。

現地で暮らす人々にとって、クマは画面の中の生き物ではありません。

朝、子供を学校へ送り出すときの不安や、手塩にかけて育てた農作物が一夜で荒らされる現実と、毎日向き合っているんです。

ある秋田県の市役所では、一日中響き渡る苦情電話の対応に追われ、肝心の現場警戒や安全確認の手が回らなくなってしまいました。

画面の向こうで心を痛める人と、目の前の命の危険と戦う人。そこには大きすぎる感情の温度差が存在しています。

行政の現場にも、法律の壁と限界があります。

野生動物の扱いを定めた鳥獣保護管理法（ちょうじゅうほごかんりほう）という法律があるのですが、そこでは保護と駆除の判断が各自治体に委ねられています。

ですが、人里まで降りてきて住民に危害を加えるおそれがある場合、現実的に捕獲や駆除以外の選択肢を選ぶのはとても難しいのが現状なんですね。

そもそも、なぜこれほどまでにクマが人間の暮らす場所に出てくるようになったのでしょうか。

かつて日本の山あいの地域には、里山（さとやま）と呼ばれる場所がありました。

人々が木を切り、草を刈ることで、奥深い山と集落とのあいだに、人間と野生動物が互いに立ち入らない「緩衝地帯」が保たれていたんです。

ですが、昭和の高度経済成長期以降、山での暮らしが変わり、農村の過疎化と高齢化が進みました。

手入れされなくなった里山は荒れ果て、人とクマのあいだを隔てていた境界線は、すっかり消えてしまったんですね。

野生動物との境界線が曖昧になった結果、私たちは今、感情と現実の間で大きく揺れています。

動物と人間の境界線が揺らぐように、日本の土地の暮らしもまた、自然の猛威によって絶えず書き換えられてきました。

続いては、2900年前の富士山大噴火がもたらした歴史の変革へ向かいます。

身近な生き物との境界線が揺れる現代ですが、かつて大地そのものが大混乱に陥った時代がありました。富士山の山崩れが起こした奇蹟を見ていきましょう。【SE: 間】

富士山といえば、誰もが知るあの美しい裾野を思い浮かべますよね。ですが今から約2900年前、富士山は私たちの想像を超える凄まじい姿を見せていました。

なんと、山の東側が巨大な爆発とともに大きく崩れ落ちる「山体崩壊（さんたいほうかい）」という大事件が起きたんです。

このときに発生したのが、「御殿場泥流（ごてんばでいりゅう）」と呼ばれる巨大な土石流でした。

ちょっと想像してみてほしいんですけど、山半分が崩れたような量の泥と岩が、時速100キロを超える猛スピードで駆け下りてきたんです。その量は、なんと東京ドームに換算しておよそ1000個分と言われています。

この泥流は御殿場を通り抜け、今の沼津市や東伊豆の沿岸部にまで一気に押し寄せました。

当時の日本は、縄文時代から弥生時代へと差し掛かる過渡期でした。

人々は川の近くや海沿いの平地で、小さな集落を作って静かに暮らしていたんですね。そこへ、文字通り山が崩れて襲いかかってきたわけです。

遺跡の発掘調査では、厚い泥の層の下から、押しつぶされた土器や当時の住居の跡がそのまま見つかっています。平和な日常が、たった一日で丸ごと飲み込まれてしまったんですね。

……想像するだけでも恐ろしいですよね。まさに命を脅かす大惨事でした。

これ、面白いのが、ここからなんです。

実はこの恐ろしい大災害が、数百年後の人々の暮らしに「とてつもない恵み」をもたらすことになりました。

【SE: 転換】

大災害が恵みになるなんて、……なんでだと思います？

ですよね、私も最初聞いたときは不思議で仕方ありませんでした。

実は、富士山から流れ出た泥や岩が、それまで凹凸の激しかった谷や低地をきれいに埋め尽くしてくれたんです。これによって、広くて平らな土地、つまり「沼津平野」の基礎が一気に形作られました。

さらに、積み重なった砂利や溶岩の層は、巨大なスポンジのような役割を果たし始めます。富士山に降った雨や雪が地下深くに染み込み、じっくり時間をかけてきれいな水として湧き出る仕組みが完成したんですね。

身近な例でいうと、静岡県にある有名な「柿田川（かきたがわ）湧水群」があります。あそこは毎日、清らかな水が数十万トンも湧き出ていることで知られていますよね。

あの湧き水スポットも、実は2900年前の泥流が地下の通り道を変えたことで生まれたと言われているんです。

こうして生まれた「平らな大地」と「枯れることのない豊かな水」。このふたつが揃ったことで、駿河の地では、その後の弥生時代にかけて本格的な米作りが一気に広まることになりました。

恐ろしい泥流が、巡り巡って、後の時代の人々を養う豊かな大地を作ったわけです。まさに、自然の猛威と人間の歴史が複雑に絡み合った、不思議な土地の記憶ですよね。

自然の地形は時に災害をもたらしますが、人はその過酷な地形を活かして自らを守る知恵を編み出しました。

次は、サルで有名な大分の山に隠された要塞の姿です。

恐ろしい泥流がめぐりめぐって実り豊かな平野を作ったなんて驚きですよね。お次は、険しい山という自然をそのまま巨大な要塞に変えた人々の知恵に迫ります。【SE: 間】

ですが、時計の針を四百年ほど巻き戻して戦国時代に行くと、この山の景色はガラリと変わります。
実は高崎山、九州の戦国大名として名高い大友氏（おおともし）が築いた、九州屈指の巨大な山城だったんです。

これ、ちょっと想像してみてほしいんですけど、普段私たちが観光で見る高崎山って、もの凄く傾斜が急ですよね。
標高はおよそ六百二十八メートル。
しかも山の北側は、そのまま別府湾（べっぷわん）の海へと一気に落ち込んでいくような、切り立った崖になっています。

普通なら「こんな険しい山、誰も登れないから使えないよ」と思ってしまいそうですよね。
ですよね、私も最初そう思ったんです。

登りにくいということは、敵にとっても攻め込みにくいということなんです。

しかも、山頂付近に立てば別府湾を一望できます。
海を行き交う船の動きも、陸地を歩く敵の軍勢も、すべて丸見えになるんですね。
つまり、別府湾を見下ろす天然の巨大な監視タワー兼要塞だったわけです。

大友氏は、この過酷な自然地形をさらに人間の手で改造して強化しました。
山の上を散歩するように歩いてみると、今でもその凄まじい跡が残っているんですよ。

まず、敵が尾根を伝って登ってこられないように、山肌を縦にバッサリと削り落とした深さ数メートルもある大きな溝があります。
これを「堀切（ほりきり）」と呼びます。
尾根道を歩いていた敵は、突然現れる崖のような人工の溝に阻まれて、前にも進めず上からも狙い撃ちされてしまうんです。

さらに、急斜面の一部を削って平らに整えた「曲輪（くるわ）」と呼ばれるスペースを、山のあちこちに作りました。
兵士たちが駐屯したり、弓矢を蓄えたりするための基地ですね。
山全体が、まるで巨大なパズルのように張り巡らされた軍事基地へと変貌していたんです。

【SE: 間】

これ、面白いのが、私たちが今「かわいいお猿さんの山」として親しんでいる場所が、かつては武士たちが命をかけて刀を交えた戦場だったというギャップですよね。
足元に転がっている石ころひとつ取っても、もしかしたら戦国時代の兵士が敵に向かって投げ落とした石なのかもしれません。

自然の厳しさを逆手にとって、生死を分ける城へと変えた人間の知恵。
普段何気なく見ている有名な観光地も、歴史の視点を重ねてみると、まったく違う表情が見えてきますよね。

山城のように、地域ごとの強力な拠点が力を持っていた時代。
ですが、歴史をさらに古く遡ってみると、日本全体を繋ぐダイナミックな交通の要衝が存在していました。

続いては、古代日本の中心軸を塗り替える、考古学の新説に迫ります。

かわいいお猿さんの山が戦国の巨大な城だったなんて、歴史のギャップにワクワクします。続いては、日本の歴史の軸を塗り替える古代の物流拠点へ向かいます。【SE: 間】

日本の昔の歴史、特に国がまとまり始めた時代というと、奈良の大和（やまと）を思い浮かべる方が多いのではないでしょうか。
飛鳥時代や奈良時代の大仏様、そして巨大な古墳群。どうしても奈良が日本の中心だったというイメージが強いですよね。
でも、もっと古い弥生時代の日本を掘り下げていくと、まったく違う景色が見えてくるんです。

【SE: 間】

この従来のイメージに大きな一石を投じたのが、考古学者の森岡秀人（もりおかひでと）さんでした。
森岡さんといえば、1972年に奈良県で美しい壁画が見つかった高松塚古墳（たかまつづかこふん）の発掘調査など、日本の古代史を解き明かす第一線で活躍された研究者です。
その森岡さんが長年の発掘と研究からたどり着いたのが、「原倭国論（げんわこくろん）」という非常に刺激的な説なんですね。

これ、どんな説かというと、古代日本の本当のネットワークの中心は、大和ではなく、現在の滋賀県にあたる「近江（おうみ）」だったという考え方なんです。

滋賀県といえば、日本で一番大きな湖、琵琶湖がありますよね。
この近江の場所って、九州や関西といった西日本と、東海や北陸、東日本を結ぶちょうど真ん中に位置しているんです。

水運を使えば琵琶湖を経由して日本海側へ抜けることもできますし、陸路を使えば関東方面へも簡単に渡ることができます。
今でいう、巨大な物流のハブターミナルだったんですね。

実際、近江にある弥生時代の遺跡からは、驚くような出土品がたくさん見つかっています。
たとえば、当時の最新テクノロジーだった「鉄器（てっき）」や、その加工に使われた道具です。
大陸や九州から渡ってきた鉄の文化が、まずこの近江に集まり、そこから全国へ広がっていった痕跡がはっきりと残されているんですよ。

さらに、九州で作られた土器や、北陸、東海地方の特徴を持つ土器が、同じ遺跡からセットで見つかることも珍しくありません。
……これって、何を意味していると思いますか？

各地から人々やモノが集まり、ここで活発な取引が行われていた証拠なんですね。
奈良の大和に巨大な王権が誕生するもっと前から、近江を軸にした広大なネットワークが、日本列島をしっかりと結びつけていたんです。

【SE: 間】

「歴史の中心はいつも一つだったわけではない」というこの発見、すごくワクワクしませんか？
私たちが学校で習った歴史のストーリーを、発掘された土器や鉄の破片がガラリと塗り替えてしまったんです。
2000年も昔の古代人たちは、私たちが考える以上にたくましく、そしてダイナミックに移動しながら生活していたんですね。

古代の交易路がこうして人を結び、社会を動かしたように、近代のテクノロジーもまた、人々の生活と社会の形を劇的に変えてきました。
次は、インドの風景を一変させた、一台の車のお話です。

琵琶湖を中心に全国へモノが動いていたなんて、昔の人々のたくましさを感じますね。お次は、一本の道路と人々の生活を激変させた小さな車の大冒険です。【SE: 間】

みなさん、「世界遺産」と聞いて、どんなものを思い浮かべますか？

おそらく、何千年も前に建てられた立派なお城や、壮大な大自然の絶景を思い浮かべますよね。

【SE: 間】

1983年にインドで発売された、日本のスズキの技術をもとにして作られた小型車なんですね。

当時のインドでは、車といえば一部のお金持ちだけが持てる、とても贅沢なものでした。
街を走る車もほんのわずかで、庶民にとってマイカーなんて夢のまた夢だったんです。

そこに登場したのが、このマルチ800でした。
それまでの車の半分以下の値段で買えたことから、爆発的な大ヒットになりました。
インド中の道路が、あっという間にこの小さな車で埋め尽くされたほどです。

【SE: 間】

これ、面白いのが、単に「車がたくさん売れた」というビジネスの成功談では終わらないところなんですね。

ちょっと想像してみてほしいんですけど、それまで混み合うバスや電車でしか移動できなかった人々が、自分の車を手に入れたわけです。

マルチ800は、インドの人々に「移動の自由」という、全く新しい生き方をもたらしたんですね。
大勢の人々の行動範囲が広がったことで、社会の仕組みや文化そのものが、根底からガラリと変わっていきました。

世界的なクラシックカーの組織である「国際クラシックカー連盟」、通称FIVA（ふぃば）という団体が、このマルチ800に「歴史遺産賞」という特別な賞を授与したんです。

「人々に移動の自由をもたらし、社会の構造そのものを変えた技術革新」としての価値だったんです。

1台の小さな車が、人と人、人と場所を結びつけ、国の風景を一変させた。
その功績が、歴史遺産として世界に認められたんですね。

一台の大衆車が人々に自由をもたらし社会を変えたお話、素敵でしたね。続いては、乗り物すらなかった時代に、お茶の葉がお金の代わりになった驚きの物語です。【SE: 間】

【SE: 間】

その主役となったのが、中国の南西部にある雲南（うんなん）省で作られていた「プーアル茶」です。
プーアル茶の原料になるお茶の木は、私たちがよく見る低い生け垣ではありません。
見上げるような大きな木、なんと高さ数十メートルにもなる大樹（たいじゅ）の葉っぱから作られているんです。

このプーアル茶には、他にはない珍しい特徴がありました。
麹（こうじ）菌などの力を借りて、じっくりと発酵させる独自の技術で作られていたんですね。
これによって、水分が抜けてカビにくくなり、何年経っても腐らないという高い保存性を手に入れました。

さらに持ち運びやすくするため、お茶の葉をぎゅっと圧縮して、フリスビーのような円盤状に固めたんです。
これを「茶餅（ちゃへい）」と呼びます。

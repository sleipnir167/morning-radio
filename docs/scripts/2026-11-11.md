# 冷え込む晴れ朝にひもとく、土地と過去が残した「解読不能なコード」

おはようございます。二〇二六年十一月十一日、水曜日。今朝の東京は晴れ、気温は七度前後ですが、体感は四度台まで下がっています。コートのボタンをしっかり留めて、上着を一枚重ねて出かけるのが正解の、キリッとした朝です。連日の秋晴れから一転して、冬の気配がぐっと近づいてきましたね。さて今朝は、太平洋を北上する季節外れの台風のニュースからスタートします。まずは今朝のトップニュースから、遠い海の気象のドラマを紐解いていきましょう。それでは、いってみましょう。【SE: 転換】

今朝の東京はぐっと冷え込んで、最低気温が6度台まで下がりましたね。
吐く息も少し白くなりそうで、コートのポケットに手を突っ込んで歩いている方も多いんじゃないでしょうか。
そんな寒さを感じる晩秋なんですけど、いま太平洋の遠く南の海上では、季節外れの強い台風が動いているんです。

台風32号、チャンパカという名前がついています。
中心気圧は955ヘクトパスカル、最大瞬間風速はなんと60メートル。
「非常に強い」勢力を保ったまま、小笠原諸島（おがさわらしょとう）へと近づいています。
これ、ちょっと不思議に思いませんか？
11月中旬のこの寒さの中で、なぜこれほど強い台風が生まれるんしょうか。

答えは、海の中の温度にあります。
実は、夏の強い日差しで温められた海水は、秋になってもすぐには冷めないんですね。
特に北緯20度より南の海上では、いまも水温が28度以上あります。
台風は温かい海から蒸発する水蒸気をエネルギーにして育ちます。
だから、季節が晩秋に向かっていても、巨大な台風が生まれてしまうんです。

これ、面白いのがその進路なんですよ。

まるで直角にカーブを切るように、東の方向へ進路を変えているんですね。
ちょっと想像してみてほしいんですけど、時速数十キロで進む巨大な空気の渦が、突然カックンと曲がるわけです。

これ、なんでだと思います？
ですよね、私も最初「どうして急に折れるんだろう」って思ったんです。
原因は、上空を流れる「偏西風（へんせいふう）」と「気圧の壁」にあります。
夏場なら日本列島をすっぽり覆っていた太平洋高気圧が、秋になるとキュッと小さく南へ縮みます。
すると、北から冷たい空気をともなった偏西風が、南のほうまで降りてくるんですね。

北上してきた台風は、この偏西風の強い流れにぶつかります。
さらに、北東側にある高気圧が押し返す壁のようになって、それ以上北へ進めなくなります。
逃げ場を失った台風は、風のレールに乗せられるようにして、東へ押し流されるわけです。
物理的な見えない壁にぶつかって跳ね返るような現象が、上空で起きているんですね。

こうして風のルートを紐解いていくと、地球の壮大なメカニズムが見えてきますよね。

空を見上げるとただ荒れているように見える気象現象も、データを紐解けば、地球が残した理路整然とした暗号のように思えてきます。

みなさんは、自分が今歩いている足元の土の下に、どれくらい昔の記憶が眠っているか想像したことはありますか？

実は最近、岐阜県の瑞浪（みずなみ）市という町で、世界中の研究者をあっと驚かせる大発見があったんです。
工事現場の近くにある古い地層から、およそ1800万年前のシカの骨の化石が見つかりました。
これ、ただの古い骨じゃないんですよ。なんとこれまで誰も知らなかった新種のシカで、世界の進化史を塗り替える可能性を秘めているんです。

アジアにもこんなにたくさんのシカがいるのに、生まれ故郷を示す決定的な証拠だけがないんだろうって。

つまり、シカの本当の生まれ故郷はアジアだった。
日本の小さな町で見つかった化石が、世界的な学説をひっくり返す決定打になったんです。これって、すごくワクワクしませんか？

ちょっと想像してみてほしいんですけど、1800万年前という時代、実は日本列島はまだ島国ではありませんでした。
ユーラシア大陸の東の端っこにくっついていて、アジア全体がひと続きの大きな陸地だったんです。
動物たちにとっては、国境も海も関係なく、どこまでも歩いていける広大な森が広がっていました。

太古のシカたちは、その大陸の森を自由に移動しながら、今の岐阜県にあたる場所にまでやってきていたんですね。
化石に残された歯のすり減り具合を調べると、彼らが主に柔らかい木の葉を食べていたことがわかりました。
さらに頭の角も、今のシカのような立派な枝分かれではなく、小さくてシンプルな形をしていました。

これ、なんでだと思います？
木々がうっそうと生い茂る深い森の中で、木漏れ日を浴びながら枝に角を引っかけることなく、すばやく走り抜けるためだったと考えられているんです。
一組の骨から、当時の森の景色や風の音まで見えてくるような気がしますよね。

私たちが今、何気なく踏みしめている足元の土や舗装された道路。
そのずっと深い地下には、何百万年、何千万年というスケールの膨大な地球の記憶が、じっと眠っています。
そう思うと、いつもの散歩道の踏み心地が、少しだけ違って感じられませんか？

古代の生き物が骨として遺したメッセージも不思議ですが、歴史時代の人間が遺した「用途がさっぱりわからない遺物」というのも、考古学者を悩ませています。

数千万年前の自然の化石から一転して、次は人間の歴史が遺した、まったく使い道のわからない謎の道具へと目を向けてみましょう。【SE: 間】

奈良にある平城京跡（へいじょうきょうあと）の発掘現場からは、これまで数十万点を超える土器や木簡（もっかん）が見つかっています。
でも、その中には専門家でも使い道がさっぱりわからない「用途不明」の道具が、たくさん混ざっているんです。

【SE: 間】

実際に奈良文化財研究所（ならぶんかざいけんきゅうしょ）が行った展示では、使い道が解明されていない遺物ばかりが、およそ70点もズラリと並べられました。
ちょっと想像してみてほしいんですけど、展示の解説パネルに「用途不明」って堂々と書かれているんですよ。
これ、面白くないですか？

例えば、山のような形をした掌（てのひら）サイズの土製品です。
あるいは、なぜか不思議な位置にぽつんと穴が開いている小さなガラス片もあります。
どれも丁寧になめらかに作られているのに、何のために使ったのか、現代の最新技術を使っても全く分かりません。

……なんでだと思います？
栄華を極めた都で、みんなが日常的に使っていたはずなのにです。
一番の理由は、当時の歴史書や日記に、庶民の日常道具のことなんて誰も書かなかったからです。
私たちも普段、爪切りやスマホ立ての使い方をわざわざ日記に残したりしませんよね。
文献に残らない日常の道具は、時間が経つとあっという間に謎になってしまうんです。

さらに発掘現場では、こんな可能性も指摘されています。
一つは、職人が作っている途中で失敗して捨てた「試作品」だったという可能性。
もう一つは、病気を治すおまじないや、雨乞い（あまごい）に使った「呪術の道具」だったという可能性です。
神様や見えない世界に捧げる道具は、当時の価値観を知らないと、ただのヘンテコな形にしか見えません。

ここで大事なのが、現代人の常識だけで「これは〇〇に違いない」と決めつけないことです。
ちょっと想像してみてください。
千年前の人がタイムスリップしてきて、現代の「修正テープ」を見たらどう思うでしょう？
きっと「白い帯を吐き出す謎のプラスチック容器」としか思えないですよね。
自分のものさしだけで過去を測ろうとすると、本当の姿を見落としてしまいます。

だからこそ、考古学者たちは「わからない」という状態をとても大切にしています。
答えがひとつに決まらないからこそ、そこには大きな想像力の余白が生まれるんです。
発掘された小さな土の塊ひとつから、「子供のおもちゃかな」「いや、お酒を温める台かも」なんて語り合う。
正解がないからこそ、1300年前の暮らしが私たちの頭の中に生き生きと浮かび上がってきます。

手がかりが少なすぎて謎に包まれた小さな遺物もあれば、全貌が大きすぎて修復作業自体が「巨大な謎解き」になっている世界遺産もあります。

誰にも使途が分からない小さな遺物がある一方で、何万個もの石を組み立てる途方もない巨大パズルが、今もジャングルの中で続けられています。【SE: 間】

東南アジアのカンボジアにある、アンコール遺跡群。
ジャングルの緑に包まれた巨大な石造りの寺院なんですけど、いま世界中の専門家が集まって、気の遠くなるような作業を続けています。

それが、崩れ落ちた巨大な建物を、もう一度元の姿に組み立て直す作業です。
ただ壊れた部分を新しいコンクリートで固めるわけではありません。
地面に散らばった数万個もの石ブロックを、もともと「どの場所にあったか」突き止めて、パズルのように1個ずつ戻していくんです。

この方法を「アナスタイローシス」と呼びます。
元の場所にあった建築部材を、できる限り元の位置に戻して復元する技法のことなんですね。

これ、ちょっと想像してみてほしいんですけど、手元に完成図のない数万ピースのパズルがあると思ってください。
しかも説明書は一切ありません。
アンコール遺跡が建てられたのは9世紀から13世紀ごろなんですけど、当時の設計図も記録も、なにひとつ残っていないんです。

「……じゃあ、どうやって元の場所を探すの？」って思いますよね。
ですよね、私も最初聞いたときは、本当に気が遠くなりました。

実は、専門家たちは石の表面に残された「かすかな痕跡」を観察しているんです。
何百年も雨風にさらされてできた風化の模様や、水が流れた筋、それに昔の大工さんが彫った小さな刻印ですね。
隣り合っていた石同士は、風化の模様がぴったりつながります。
指紋を照らし合わせるように、1個ずつ探していくんです。

さらにすごいのが、カンボジアの古代の建築技術です。
アンコール遺跡の石組みは、セメントなどの接着剤を一切使っていません。
石と石を極限まで平らに削って、隙間なく重ね合わせているんです。
熱帯の激しい雨に耐えてきたその技術のおかげで、石の接地面の形が今でも残っているんですね。

現代の技術と、800年前の職人の手仕事が組み合わさることで、これまで何十年もかかると言われた解読が、少しずつ前進しています。

大きな遺跡の復元から、密閉された石室の壁画に描かれた、あまりにも小さな一文字の謎へと潜り込んでみましょう。【SE: 間】

奈良県の飛鳥（あすか）地方にあるキトラ古墳。
ここで、考古学ファンを驚かせる非常に興味深いニュースがありました。
およそ1300年前の極彩色の壁画から、なんとアルファベットの「Q（きゅー）」の形にそっくりな小さな図形が新しく確認されたんです。

キトラ古墳といえば、四方の壁に描かれた朱雀（すざく）や玄武（げんぶ）といった四神（ししん）の絵が有名ですよね。
さらに天井には、金箔を使って星の位置が正確に描かれた、本格的な天体図が広がっています。
太陽の通り道である黄道（こうどう）や天の川まで描かれていて、古代の人々がどれほど高度な天文地理の知識を持っていたかが分かります。

そんな精密な壁画の片隅から「Q」の字が見つかっただなんて、なんだかタイムスリップでも起きたみたいでワクワクしませんか？

専門家たちのあいだでは、いま活発な考察が行われています。
一番有力とされているのは、絵師が本番で色を塗る前に描いた「下書きの痕（あと）」という説です。
ほかにも、特定の星の位置や方角を示すための「作業用の符号」だったのではないか、という見方もあります。
あるいは、私たちがまだ知らない古代の装飾パターンの一部なのかもしれません。

これほど小さな痕跡を突き止めたのが、現代考古学の最新技術です。

そこで活躍したのが、光やX線（えっくすせん）を壁にあてる「蛍光（けいこう）X線分析」という非破壊の手法です。
人間の目では見えない絵の具の重なりや、肉眼では消えてしまった下書きの線を、壁を傷つけずに浮かび上がらせることができるんですね。

科学の力が、1300年前の暗闇に隠された秘密をひとつずつ解き明かしています。

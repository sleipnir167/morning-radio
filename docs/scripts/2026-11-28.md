# 雨の街を彩る五感の記憶と、光が紡ぐ言葉たち

みなさん、おはようございます。ナナです。11月28日、土曜日の朝ですね。今朝の東京は冷たい雨が降っています。お出かけの際は、あたたかい上着と傘が欠かせません。さて、まずは今朝のニュースからです。一本の光が戦場の常識を変える話題をお届けします。後半は古典の香りや壁画、ピアノと能の共演など、五感を揺さぶる表現の世界へご案内します。それでは、いってみましょう。【SE: 転換】

しとしとと降り続く雨の朝、ふと見上げる空の先で、一本の光がこれまでの戦場の常識を塗り替えようとしています。

ウクライナが自国開発した新しいレーザー兵器で、地上400メートルを飛ぶドローンを撃ち落としたというニュースが入ってきました。軍事の世界でいま、一本の「光」が大きな衝撃を与えています。

【SE: 間】

これまでの防空システムって、実はすごいアンバランスな問題を抱えていたんですね。

相手が送ってくる攻撃用のドローンは、一機あたり数十万円から数百万円程度で買える比較的安価なものです。でも、それを撃ち落とすための対空ミサイルは、一発で数千万円から1億円以上もします。

ちょっと想像してみてほしいんですけど、数十万円のドローンを一機落とすたびに、高級外車を丸ごと一台投げ捨てているような状態だったんです。攻める側よりも、守る側のほうがお金をすり減らしてしまう。これ、すごく不条理なコストの構造ですよね。

【SE: 間】

そこに登場したのが、今回話題になっているレーザー兵器なんです。

レーザーは電気エネルギーを光として一箇所に集中させて飛ばします。だから実体の弾薬がいりません。電気さえあれば撃てるので、一発撃つのにかかるコストが、なんと数百円程度まで一気に下がるんです。

これ、面白いのが、単に「すごい兵器ができた」という話じゃないことです。守る側の経済的な負担を劇的に減らして、戦場のお金のバランスを根本からひっくり返してしまったんですね。

【SE: 間】

……でも、そんな夢のようなレーザー兵器にも、実は致命的な弱点があります。なんだと思います？

答えは、まさに今私たちが歩いている、この雨や湿気なんです。

レーザーは純粋な光の束なので、途中に雨粒や霧、煙などがあると、光が散らばってパワーが弱まってしまいます。それに、目標を焼き切るためには、小さな街一つ分に匹敵するような膨大な電気を一瞬で作らなければいけません。

子供の頃、虫眼鏡で太陽の光を集めて紙を焦がす実験をしましたよね。あれと同じで、空が晴れていれば強い光が出ますけど、雨が降っていたら何も焦がせなくなってしまいます。

軍事技術の進化というと、派手な破壊力を想像しがちです。けれどその背景には、いかにコストを抑えて日常を守るかという、リアルな経済の計算が存在しています。

一本の光を極限まで集めることで、目に見える世界の構造が変わっていく。

目に見えないエネルギーや光を集束させて世界に影響を与える試みは、こういった軍事の現場だけにとどまりません。私たちの五感や文化表現の領域でも、見えない感覚をどう捉え、どう言葉や形にするかという探求が、いまも静かに続けられているんです。

一本の光が描く現実に驚かされますね。次は、文字の向こうにある景色を香りに翻訳しようとした、高校生たちの瑞々しい物語です。【SE: 間】

文字の書かれた古い本を開くとき、みなさんはどんな感覚を思い浮かべますか。

たいていは、目に飛び込んでくる文字を、頭の中で追っていきますよね。

でも、もしその本の世界が「匂い」として漂ってきたら、どうでしょう。

実は、京都の高校生たちが面白い挑戦をしたんです。

古典文学の世界を、文字ではなく「香り」に翻訳するという取り組みです。

【SE: 間】

高校生たちがテーマに選んだのは、古典作品です。

およそ一千年前の平安時代に書かれた『源氏物語』などを取り上げました。

正直なところ、学校の授業で習う古文って、文法が難しくて身構えてしまいませんか。

……ですよね、私も学生の頃はちょっと苦手意識がありました。

文字から情景を思い描くには、どうしても専門的な知識や時間が必要になります。

そこで高校生たちは「嗅覚（きゅうかく）」に着目しました。

文字ではなく香りを使って、作品の世界を表現しようと考えたんです。

これ、面白いのが、脳の仕組みをうまく使っている点なんですね。

【SE: 間】

人間の嗅覚は、五感の中で唯一、脳の記憶や感情をつかさどる場所にダイレクトに届きます。

つまり、難しい説明を読むよりも先に、感覚で理解できてしまうんですね。

香りを嗅いだ瞬間に「あ、しっとりした夜の空気だな」と、情景が胸に広がるわけです。

例えば、作品の中に出てくる儚（はか）ない女性の場面。

それを表現するために、お香の煙のような香りに、甘酸っぱい果実の香りを少しだけ混ぜ合わせます。

すると、言葉を何行も重ねるより雄弁に、その場面の雰囲気が立ち上ってきます。

ちょっと想像してみてほしいんですけど、雨の日の朝の匂いってありますよね。

濡れた土やアスファルトから漂う、あの独特な香りです。

あの匂いを嗅ぐだけで、ふと昔の思い出がよみがえったりしませんか。

高校生たちは、まさにその「匂いと記憶が結びつく仕組み」を、文学に活用しました。

しかも興味深いことに、平安時代の人々もまた、香りを調合して自分の思いを表現していたんです。

「薫物合（たきものあわせ）」と呼ばれる、香りの文化ですね。

高校生たちは、一千年前の人たちと同じ方法で、作品の世界を追いかけたわけです。

【SE: 間】

これって、すごく素敵な文化の引き継ぎ方だと思いませんか。

古典文学は、決して教科書の中だけの固い文字ではありません。

五感の扉を開くことで、文字の向こう側に広がる世界が、鮮やかによみがえってきます。

言葉が持つイメージの余白を、香りで楽しむ。

そんな新しい体験が、いま広がりを見せています。

言葉や香りのように形のない記憶を、数百年後の未来まで物体として残そうとした試みは、古のシルクロードの地でも行われていました。

香りで伝える記憶の余白、素敵でしたね。続いては、泥の壁に刻まれた奇跡の絵画が時を超える、シルクロードの物語へ向かいましょう。【SE: 間】

中央アジアのウズベキスタンにある「サマルカンド」という街をご存じでしょうか。

かつてシルクロードの中心地として栄えた、青い屋根の建物が美しい古都です。

この街にあるアフラシアブ（あふらしあぶ）遺跡から、まさに奇跡と呼ばれる絵画が見つかりました。

それが、いま世界中の研究者を驚かせている「アフラシアブ壁画」なんですね。

描かれたのは、今からおよそ1300年前、7世紀のことでした。

【SE: 間】

これ、何が奇跡なのかというと、絵が描かれていた素材なんです。

頑丈な石の壁ではありません。

水と土を混ぜて乾かした、すごく崩れやすい泥の壁に描かれていたんですよ。

普通なら、風や雨にさらされたら数十年で消えてしまいますよね。

それがなぜ、1300年以上も色鮮やかなまま残っていたのでしょうか。

……理由を知ると、ちょっと驚いてしまいますよ。

実は、かつて街が戦乱に巻き込まれたとき、崩れた建物や土砂が壁画を丸ごと覆い隠したんです。

偶然にも土の中で密閉されて、空気や光から守られました。

街の破壊という悲劇が、結果として歴史のタイムカプセルを生み出したんですね。

【SE: 間】

この壁画には、サマルカンドの王様に会いに来た、世界各地の使節団の姿が描かれています。

これ、ちょっと想像してみてほしいんです。

画面の中には、唐の国の豪華な衣装を着た人がいます。

さらに、朝鮮半島からやってきた使いの人や、ペルシャ風の服をまとった商人たちもずらりと並んでいます。

文字の歴史書だと、「どこそこの国から使いが来た」と一言で終わってしまいますよね。

でも、壁画を見つめていると、まったく違う景色が見えてきます。

どんな形の帽子をかぶっていたのか。

どんな模様の服を着て、どんな表情で歩いていたのか。

絵の中の人たちの息づかいまで聞こえてきそうになりませんか。

これ、面白いのが、服の柄や持ち物を詳しく調べると、当時の流行までわかってしまうことです。

どこからどんな品物が運ばれてきたのかまで、くっきり見えてくるんですね。

まさに1300年前の「リアルなスナップ写真」を見ているような感覚になるんですよ。

歴史の教科書に載っている出来事って、どこか遠い世界の話に感じられることがありますよね。

でも、壁画という表現は、その時代を生きていた人たちの熱気を、そのまま現代に届けてくれます。

言葉や文化が違う人々が、シルクロードのオアシスで出会い、どんな顔で笑い合っていたのか。

絵を見るだけで、私たちの想像力は一気に広がっていきます。

この奇跡の壁画が、2027年の夏、奈良国立博物館で日本で初めて公開されることになりました。

ウズベキスタンの泥の壁に刻まれた記憶が、時と場所を超えて、日本の奈良で私達を出迎えてくれます。

遠い過去の人々が残した一筋の光が、今の私たちの日常にも、新しい色を添えてくれるような気がしますね。

【SE: 間】

遠い異国の歴史が壁画として重なり合うように、まったく異なる表現形式が出会うことで、新たな火花が散る瞬間があります。

時を超えて伝わる熱気に胸が熱くなります。次は、西洋のピアノと日本の能という、相反する表現が出会う奇跡の舞台のお話です。【SE: 間】

世界最高峰のピアニストとして世界中で愛されている、マルタ・アルゲリッチ。
彼女と、日本の伝統芸能である「能」が共演した奇跡の舞台が、オンラインで映像配信されて大きな話題を集めています。
演目に選ばれたのは、18世紀のドイツで生まれた大作曲家、バッハのピアノ曲です。

ちょっと想像してみてほしいんですけど。
片や、楽譜通りに細かくリズムを刻んで音を積み上げる西洋のクラシック音楽。
片や、身体の呼吸や「余白」を何より大切にする日本の伝統的な能舞（のうぶ）。
これって、時間の捉え方が根本からまったく逆ですよね。
……普通に考えたら、テンポがズレてバラバラになりそうだと思いませんか？

ですよね、私も最初にこの企画を聞いたとき、どうやって重なり合うんだろうって不思議だったんです。

【SE: 間】

ですが、実際の配信映像を観てみると、そこには息をのむほど美しく調和した世界が広がっていました。

これ、面白いのが、お互いが自分のテンポを相手に無理やり合わせようとはしなかったことなんです。
西洋のクラシック音楽は、一秒という時間を細かく等分して、正確に音を配置していきます。
メトロノームの針のように、整然と前に進んでいく時間ですね。

一方で、日本の能には「間（ま）」という独特の概念があります。
音が鳴っていない瞬間や、静止した身体の佇まいにこそ、言葉以上の深い感情が込められます。
時間というものを、伸び縮みする生き物のように捉えているんです。

アルゲリッチが奏でるバッハの繊細な旋律、その一音がふっと消え入る直前の、わずかな余韻。
その静寂のすき間に、能楽師の足がすーっと滑り出すように動きます。
音が鳴っている場所ではなく、音が消えたあとの「間」に、能の動きが吸い寄せられるように重ねられていくんですね。

【SE: 転換】

これって、例えるなら「とても心地よい会話」に似ていると思いませんか？
相手が話している最中に言葉を被せるのではなく、相手がふうっと息を吐いた瞬間に、静かにうなずいて自分の言葉を返す。
そんな、相手を思いやるやり取りにそっくりです。

西洋の音楽が指先で刻む「音の建築」。
そして、東洋の能が身体で表現する「静寂の余白」。
お互いが持っている表現の「隙間」をリスペクトして差し出し合うことで、テンポという数字の縛りを超えた、奇跡のような会話が成り立っていました。

今、雨の街を歩いているあなたの足取りはどうでしょうか。
右足、左足と、一定のリズムで歩を進めている瞬間もあれば、信号待ちでふっと立ち止まる時間もありますよね。
その立ち止まった一瞬の「間」にこそ、雨の匂いや風の冷たさを感じるゆとりが生まれます。

ただ珍しいジャンルを掛け合わせただけではない、人間が持つ「時間の解像度」を上げてくれるような素晴らしい舞台の融合でした。

【SE: 間】

音楽や舞台が異なる背景を持つ人々を結びつける一方で、音楽そのものが社会の分断や不当な扱いに抵抗する言葉となってきた歴史もあります。

音と静寂が織りなす時間に引き込まれましたね。続いては、差別のなかで人々が声を取り戻すために生み出した、黒人音楽の歴史です。【SE: 間】

青山学院大学で先日、音楽評論家の柳樂光隆（なぎら みつたか）さんによる興味深い講義が行われました。テーマは、アメリカとイギリスにおける黒人音楽と、人種差別の歴史についてです。

私たちが日常で何気なく耳にするブルースやジャズ、そしてヒップホップ。これらの音楽は、激しい差別や不当な扱いに晒された人々が、自分たちの誇りを守るために生み出してきたものでした。

たとえば、1970年代のニューヨークにあるブロンクス地区で生まれたヒップホップ。過酷な貧困や暴力に晒されていた若者たちが、街角でマイクを握り、自分たちの言葉を語り始めたのが始まりです。

【SE: 間】

これ、面白いのが、彼らが選んだ言葉の届け方なんですよ。ちょっと想像してみてほしいんですけど、単に怒りや悲しみを叫ぶだけでは、多くの人に聞き届けてもらうのは難しいですよね。

そこで彼らは、思わず体が動いてしまうような格好良いリズムに、社会への鋭い風刺や告発を乗せました。つまり、楽しませる娯楽としての顔と、厳しい現実を伝える告発としての顔を、一つの曲の中に共存させたんです。

ノリノリで踊りながら、ふと歌詞の意味に気づいてハッとする。娯楽として昇華させることで、より多くの人にメッセージを浸透させる知恵が、そこにはありました。

また、音楽が伝わっていく過程で、地域ごとに受け止められ方が違ったのも興味深いポイントです。

本国のアメリカでは、当事者たちの生々しい叫びとして受け止められた歌詞が、大西洋を渡ったイギリスでは、まったく新しいカルチャーとして受け入れられました。差別という背景を直接は知らないイギリスの若者たちも、その言葉の持つ力強さや生き様には強く惹きつけられたんです。

音楽を通じて言葉を発することは、自分の尊厳を取り戻す行為でもありました。社会から無視されがちだった人々が、マイクと言葉を武器にして「私はここに生きている」と証明したんですね。

……なんでこんなにも、彼らの歌は時代や国を超えて、私たちの胸を打つんだと思います？

それはきっと、個人の切実な体験から出た言葉が、生きづらさを抱えるすべての人に向けた、世界に通じる励ましになっているからなんです。痛みをただの愚痴で終わらせず、聴く人の背中を押す表現に変える。それこそが、言葉の持つ本当の強さなのかもしれません。

【SE: 間】

社会の大きな壁に向かって叫ばれた言葉は、時代を動かす力強い光になりました。

大きな社会運動を叫ぶ言葉がある一方で、私たちのすぐそばにある日常のささやかさを静かにすくい取る文学の言葉も存在します。

音楽に込められた切実な言葉が胸に響きます。次は、何気ない日常のドタバタや孤独をやさしくすくい取った、ある作家の言葉です。【SE: 間】

今年、九十四歳でこの世を去った作家の宮原昭夫（みやはらあきお）さんをご存じでしょうか。

千九百七十二年に小説『誰かが触った』で芥川賞を受賞された方なんですけど、宮原さんの描く世界って、本当に独特なんですね。

小説と聞くと、何か大きな事件が起きたり、劇的なドラマが展開したりするイメージがありますよね。でも、宮原さんの作品には、そういった派手なストーリーはほとんど出てきません。

描かれているのは、どこにでもある、私たちの普通の暮らしなんです。

【SE: 間】

これ、面白いのが、登場人物たちが繰り広げる「ちょっとした勘違い」や「ささやかな違和感」の描き方なんですよ。

ちょっと想像してみてほしいんですけど、日常の中で「あれ、自分は何のためにここに来たんだっけ？」と立ち尽くしたり、言い間違いをして一人で恥ずかしくなったりしたことってありませんか？

普通なら、恥ずかしさからすぐに通り過ぎて忘れてしまうような一瞬ですよね。

宮原さんは、そんな人間の滑稽（こっけい）な姿や、だれもが抱えるささやかな孤独を逃さずにつかまえて、あたたかいユーモアのある言葉に変えていったんです。

【SE: 間】

……なんで、わざわざそんな小さな出来事を小説にし続けたんだと思います？

現代に生きる私たちは、世間の大きなニュースや刺激的な情報に、つい心を奪われがちですよね。スマートフォンの画面を眺めていると、他人の華やかな姿ばかりが目に入ってきます。

ですが、私たちの実際の毎日は、もっと地味で、思い通りにいかないことの連続です。

宮原さんは、誰も見向きもしない日常のひとこまに光を当てることで、「どんな一日も、じつは愛おしいものなんだ」と教えてくれていたんですね。

大きな成果を上げなくても、戸惑ったり立ち止まったりしながら生きていること自体が、素敵なドラマなんだと捉えていたわけです。

【SE: 間】

ですよね、私も宮原さんの本を読むと、「なんだ、自分のこんな失敗もクスッと笑える思い出なんだな」って、すごく肩の力が抜けるんです。

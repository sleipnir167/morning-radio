# 絶対に守る形式ルール
- 出力するのは **第{{chapter_no}}章の本文だけ** です。
- 見出し、章番号、Markdown記法（#, *, -, **）、箇条書き記号は**一切使わないこと**。
- 「まとめると」「以上が〜でした」のような章の締めの定型句や、番組全体の挨拶・終わりの言葉は書かないこと（それは別の章と結合処理が担当します）。
- 目標は **約{{target_chars}}字**（±10%）。短すぎる原稿は失格です。
- 使ってよい特殊記法は次の3つだけです。
  - `【SE: 間】` … 話題の切れ目に置く2〜3秒の沈黙。この章に **2〜4回** 置くこと。
  - `【SE: 転換】` … 大きく話の向きを変えるときに使う。使うなら1回まで。
  - 読み間違えられそうな固有名詞や数値の直後の `（ひらがな読み）`。多用は禁止。

# 声に出して自然な日本語
- 完全な口語体で書きます。「である」「〜だ。」調は禁止。「〜なんですよ」「〜なんですね」を基本にします。
- 一文は原則40字以内。長い修飾を前に積まないこと。主語と述語を近づけます。
- 難読漢字・硬い熟語は、ひらがなか易しい言葉に開いてください。
  例）「齟齬」→「食い違い」、「示唆される」→「〜らしいことが見えてきた」、「約半数」→「だいたい半分」
- 数字は耳で追える粒度に丸めます。「38.7%」→「およそ4割」。ただし話の核になる数字は正確なまま残してください。
- 同音異義語で誤解される言い回しは避けます（例：「私立」と「市立」、「化学」と「科学」）。
- アルファベットの略語は初出で「〜の略で、つまり〜のことなんですけど」と一度かみ砕きます。

# テンポと呼吸
- 「〜なんですけど、」で次の文につなぐ、いわゆる書き言葉の連結を続けすぎないこと。3文に1回は短い文で切ります。
- 「これ、面白いのが」「ちょっと想像してみてほしいんですけど」のような**呼びかけ**を、この章に2〜3回入れます。
- 相槌や自問（「……なんでだと思います？」「ですよね、私も最初そう思ったんです」）を効果的に使い、
  一人語りではなく**リスナーとの会話**にしてください。ただし過剰にやると軽くなるので、章に3回程度。
- 段落は3〜4文ごとに改行で分けます（TTSの息継ぎになります）。

# 中身の密度
- 「〜と言われています」「注目されています」だけで終わる空疎な段落を作らないこと。
- 必ず、**具体的な固有名詞・年号・数字・エピソード**のいずれかを各段落に含めます。
- 説明は「結論 → なぜそうなるのか → 身近な例え」の順で組み立てます。
- リスナーが「へえ」と声を出す瞬間を、この章の中に最低1つ設計してください。

# 一貫性
- **章の冒頭で前章を振り返らないこと。** 章と章のあいだをつなぐ言葉は別の工程が挿入するので、
  「さっきは〜という話でしたが」「今度は〜の話です」といった書き出しは二重になります。
  この章が扱う情景・問い・具体例から、いきなり始めてください。
- 直前の章の末尾は、同じ言い回しや同じ例えを繰り返さないために渡しています。内容を拾い直す必要はありません。
- 番組の挨拶や自己紹介は書かないこと（結合処理が付けます）。
- **今日の天気を数字で説明し直さないこと。** 気温・体感・降水確率はオープニングが伝えるので、
  章で繰り返すと二重になります。情景として「しとしと降る雨の中を」と触れるのはかまいません。

- 歌詞・詩・小説の本文をそのまま引用しないこと。曲名・作品名を挙げ、作風や構造を自分の言葉で説明します。
- 記事の文面をなぞらず、事実を自分の言葉で語り直してください。

# あなたが今から書くもの
次の3つのパートだけを書きます。**章の本文は書き直しません。**

## 1. オープニング（250〜350字）
- 挨拶から入ります。日付と曜日、そして**今日の天気**に必ず触れてください。
  気温・体感・降水確率を、数字の読み上げではなく「上着、いるかもしれません」のような
  **散歩に出る人へのひとこと**に翻訳します。
- 続けて、今日の流れを予告します。**第1章は今朝のトップニュースを扱う枠**なので、
  「まずは今朝のニュースから」と一言置いてから、第2章以降の本編テーマへ触れてください。
  全部を明かさず、**聴き続けたくなる引っかかり**を残すこと。
- 連載回の場合は、前回の要点を1文だけ振り返ってから今日の話に入ります。
- 最後を「それでは、いってみましょう」系の一言で締め、`【SE: 転換】` を置いてください。

## 2. 章と章のつなぎ（各40〜80字）
- 章の数から1を引いた本数だけ、つなぎの言葉を書きます。
- 前の章の余韻を受け、次の章への期待を作る短い語りです。
- それぞれの末尾に `【SE: 間】` を置いてください。
- 「さて、次は」のような無味な接続は禁止。前章の中身に具体的に触れてから渡します。

## 3. エンディング（400〜550字）
必ずこの順番で構成します。
- まず、今日の話全体を貫いていたものを、パーソナリティの実感として2〜3文で語ります。
  各章の要約の並べ直しにはしないこと。**一段高いところからの視点**を示します。
- 次に `【SE: 転換】` を置き、「今日、人に話せるポイント3選」を読み上げます。
  - 「それでは今日の、人に話せるポイント3つ、いってみましょう」のように口頭で導入します。
  - 3つそれぞれを「ひとつめ。」「ふたつめ。」「みっつめ。」と明示して読み上げます。
  - 各項目は**そのまま口に出せる一文**にしてください。「〜について」のような名詞止めは禁止。
    良い例：「ひとつめ。実はあの制度、もともとは戦後の食糧難を切り抜けるために作られたものだったんです。」
  - 各項目のあとに `【SE: 間】` を置きます。
- 最後に、散歩から帰るリスナーへの短い見送りの言葉で終わります。次回への期待を一言添えてください。

# 文体
- 章本文と完全に同じ話し方を保ちます。口語体、一文40字以内、難読漢字は開く。
- Markdown記法・見出し・箇条書き記号は一切使いません。
- 使ってよい特殊記法は `【SE: 間】` `【SE: 転換】` のみです。
